# 進金生能源 6692 ｜ 客戶用電分析與「大光小儲」提案平台 (McKinsey Edition)

> **視覺規範**：麥肯錫顧問視覺體系（McKinsey Deep Navy `#051C2C` ✕ Royal Blue `#005EB8` ✕ Data Cyan `#00A3E0`）  
> **技術架構**：GitHub Pages 純前端靜態託管 ✕ Supabase BaaS (PostgreSQL + Storage + RLS) ✕ PDF.js / Tesseract OCR / Gemini Vision ✕ SheetJS ✕ Chart.js  
> **核心定位**：協助業務團隊從客戶**每個月的台電電費單**或**台電 15 分鐘高壓 AMI 資訊圖**出發，自動辨識關鍵欄位、儲存於雲端結構化資料表、供一鍵輸出下載 Excel/CSV，並結合台電兩段式/三段式費率進行**「大光小儲（最大化屋頂光電自發自用 ＋ 精準小容量儲能削峰套利）」**提案模擬。

## 🌟 核心功能模組

### MODULE 1：客戶每月電費單自動辨識與結構化資料表（首發核心功能）
1. **多格式單月/批次拖曳上傳**：
   - 支援 **台電電子帳單 PDF**（透過 `PDF.js` 原生文字秒級解析）、**紙本拍照或掃描影像 JPG/PNG**（內建 `Tesseract.js` 本地 OCR 與選用 `Gemini Vision AI` 雙引擎）、以及 **Excel / CSV 批次帳單匯入**。
2. **自動辨識 25 項台電電費單核心欄位**：
   - **基本識別**：客戶公司名稱（戶名）、台電 11 碼電號、計費年月 (`YYYY-MM`)、季節別（夏月 6~9 月 / 非夏月）、時間電價方案（高壓二段式 / 高壓三段式 / 特高壓三段式 / 批次生產等）。
   - **契約與需量 (kW)**：經常契約、半尖峰契約、週六半尖峰契約、離峰契約；當月經常最高需量（自動偵測是否超約並標示紅色警示）、半尖峰/週六/離峰最高需量。
   - **分段度數 (kWh)**：尖峰度數、半尖峰度數、週六半尖峰度數、離峰度數、當月總度數。
   - **費用結構與功因 (NT$ / %)**：功率因數 (%)、基本電費、流動電費、超約附加費、功因調整費、總應繳電費、平均每度單價 (元/度)。
3. **互動式校對、篩選與輸出下載**：
   - 支援在網頁表格內依客戶名稱、季節（夏月/非夏月）、關鍵字篩選，並可隨時點擊「編輯」開啟欄位校對視窗微調。
   - **一鍵輸出下載 Excel (`.xlsx`)**：自動產出含「`1_每月電費單結構化明細`」與「`2_大光小儲診斷摘要`」雙分頁之顧問級報表，亦支援匯出標準 UTF-8 `.csv` 與下載批次匯入範本。
4. **McKinsey 月度用電結構與超約削峰視覺化圖表**：
   - 自動繪製「各月份尖/半尖/週六半尖/離峰度數堆疊圖 ✕ 平均單價趨勢線」與「經常契約容量 vs. 最高實測需量削峰診斷圖」。

### MODULE 2：台電 15 分鐘高壓曲線 ✕「大光小儲」協同模擬
- 可由 MODULE 1 電費單**一鍵帶入客戶契約容量與最高需量**，或上傳**台電 AMI 15 分鐘需量數據**。
- 動態模擬 **「大光（屋頂型太陽能光電 kWp 日間自發自用）」** 疊加 **「小儲（1~2 台 125kW/261kWh 儲能鎖定 16:00~22:00 夜尖峰套利與超約削峰）」** 之 24 小時淨負載曲線，並提供 6×3 IRR 策略矩陣與 15 年專案現金流。

### MODULE 3：Supabase 雲端資料庫與業務團隊共享
- 所有上傳之原始電費單自動存入 Supabase Storage (`btm-files` 儲存桶)。
- 所有辨識出之電費單結構化資料自動寫入 Supabase PostgreSQL `public.electricity_bills` 資料表；光儲提案寫入 `public.btm_proposals` 資料表。
- 支援產生「業務團隊免設定分享連結 (`#sb_url=...&sb_key=...`)」，業務點開即可直接共用雲端資料庫。

## 🛠️ Supabase 後端配置指南（一次性設置）

1. 登入 [Supabase Dashboard](https://supabase.com/)，進入專案之 **SQL Editor**。
2. 複製並執行本專案根目錄下 [`supabase-schema.sql`](supabase-schema.sql) 的完整 SQL 語法（或在網站右上角點擊「Supabase 雲端設定」→「複製建表 SQL」）：
   - 自動建立 `public.electricity_bills`（每月電費單結構化資料表）與 `public.btm_proposals`（大光小儲提案表）。
   - 自動啟用 Row Level Security (RLS) 行級安全策略與 `btm-files` 公開儲存桶權限。
