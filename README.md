# 進金生能源 6692 ｜ 錶後儲能用電大戶收益試算與投報率評估平台

> **技術架構**：純前端靜態託管 (GitHub Pages) ✕ Supabase BaaS (Auth / Database / Storage) ✕ SheetJS ✕ Chart.js  
> **核心定位**：專門為台灣**用電大戶（契約容量 800kW 以上至數 MW）**設計之錶後儲能（BTM）多重價值疊加與 15 年現金流評估算力系統。業務團隊可直接在網頁上傳客戶之台電 AMI 需量數據（CSV / Excel）或電費單 PDF，百毫秒內即時獲得 6×3 IRR 策略矩陣與完整 15 年專案融資財務精算。

---

## 🚀 系統功能亮點

1. **業務團隊數據直傳與自動解析**：
   - 支援拖曳上傳客戶之**台電 AMI 智慧電表 15 分鐘 / 逐時用電需量數據 (CSV / Excel)**。
   - 瀏覽器端純前端解析，自動聚類出 24 小時典型工作日與非工作日負載曲線、計算最高尖峰需量 (Peak Demand kW)、平均底載 (Base Load kW) 與尖離峰比。
   - 自動精準推薦**最優契約容量 (kW)** 與 **儲能櫃台數配置 (1台 / 2台 / 3台)**。
2. **電費單 PDF 雲端附加與備查**：
   - 支援直接上傳客戶電費單 (PDF / 圖檔)，自動直傳至 Supabase 雲端儲存桶 (`btm-files`)，與試算提案永久關聯。
3. **五重多元價值堆疊 (Value Stacking) 與 6×3 策略矩陣**：
   - **時間電價差套利 (TOU Arbitrage)**：夜間離峰充電、午後夜尖峰放電。
   - **日選 2 小時需量反應 (DR 2h)**：台電指定時段抑低用電回饋。
   - **電力交易平台即時備轉 (Spinning Reserve)**：單一用戶 (Direct) vs. 聚合商模式 (Aggregator)。
   - **契約容量削峰 (Peak Shaving)**：調降經常契約容量減少基本電費，杜絕超約罰款。
   - **用電大戶條款義務抵減**：400 小時義務時數型減免試算。
4. **完整 15 年專案融資財務精算 (DCF)**：
   - 自有資金 (30%) ＋ 銀行專案融資 (70%, 2% 年息, 7年本利平均攤還)。
   - 考慮 LFP 電池第 1 年 0%、第 2~15 年每年 2% 等額容量衰減。
   - 一鍵匯出包含 18 個詳細分頁之財務精算模型活頁簿 (`.xlsx`)。
5. **Supabase 團隊提案庫與一鍵免設定分享**：
   - 試算結果一鍵同步至雲端資料庫 `btm_proposals`，跨業務跨裝置即時共享與調閱。
   - 支援產生專屬一鍵分享連結 (`#sb_url=...&sb_key=...`)，同事點開即自動連線，完全無需手動輸入金鑰。

## 🛠️ Supabase 後端一鍵配置指南 (一次性設置)

本專案遵循 `github-supabase-web` 標準規範，採用公開 `anon key` 搭配 PostgreSQL 行級安全 (RLS)：

### 步驟 1：建立資料表與 RLS 安全原則
登入 [Supabase Dashboard](https://supabase.com/)，進入專案之 **SQL Editor**，執行本專案之 [`supabase-schema.sql`](supabase-schema.sql) 完整內容即可完成：
- 建立 `btm_proposals` 提案紀錄資料表。
- 啟用 Row Level Security (RLS) 並配置公開讀取與業務寫入原則。

### 步驟 2：建立 Storage 儲存桶
1. 進入 Supabase 左側選單 **Storage** → 點擊 **New bucket**。
2. 名稱輸入：`btm-files`。
3. 勾選 **Public bucket**（允許公開下載電費單與數據）。
4. （可選）於 Configuration > Policies 確認具有 `INSERT` 與 `SELECT` 權限。

## 💼 業務團隊推案操作 SOP

```mermaid
flowchart LR
    A["1. 拖曳上傳客戶電表 CSV / 電費單"] --> B["2. 自動解析 24H 負載與推薦機台"]
    B --> C["3. 點選 6x3 IRR 熱圖與 15 年現金流"]
    C --> D["4. 儲存至 Supabase 提案庫 ＆ 匯出 Excel"]
```

1. **打開線上網址**：在瀏覽器開啟部署之 GitHub Pages 頁面。
2. **上傳數據**：
   - 方式 A：直接拖曳客戶台電需量 CSV 或 Excel 檔案至「上傳客戶用電數據」方框。
   - 方式 B：點擊「載入示範數據 (1000kW 典型大戶)」體驗一鍵解析效果。
   - 附加電費單：點擊「附加客戶電費單」上傳 PDF 文件。
3. **選擇策略與查看財務回報**：
   - 切換至步驟 2，系統自動產生 6 種策略在 1~3 台機組下的 IRR / ROI 熱力圖。
   - 點選最優之「電價套利-日選2h-即時聚合」（2台機組 IRR 高達 44.81%，回本年限僅 2.3 年）。
4. **雲端存檔與產出報表**：
   - 切換至步驟 3，填寫客戶公司名稱後點擊「確認儲存至 Supabase 提案庫」。
   - 點擊「匯出 18 分頁 Excel」下載完整活頁簿，直接作為專案融資或向客戶高層簡報之附錄！
